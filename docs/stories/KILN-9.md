# KILN-9: 3D viewer

- Release: v0.2 · Status: doing · Owner: Claude (deliver-loop)

## Story

As an **art lead reviewing a model**, I want to open a model version in an interactive 3D viewer — turn it, zoom in and move around it — so that I can judge the whole model, not only the one angle of its still preview.

INVEST: Independent ☑ (models, versions and previews exist since KILN-5/30) · Negotiable ☑ · Valuable ☑ · Estimable ☑ · Small ☑ (one API field, one page, one lazily loaded scene) · Testable ☑

## Non-functional

- Security (OWASP A03/A08): the file is untrusted. It is fetched by the app itself (`credentials: 'omit'`, `redirect: 'error'`), capped at 256 MB (the worker's `MODEL_MAX_BYTES`; the API's 500 MiB upload limit is wider), checked before parsing (magic, version, length, JSON chunk ≤ 16 MB like the worker; any buffer `uri`, any image `uri` that is not `data:` → refused) and parsed from memory with a loading manager that turns any non-`blob:`/`data:` URL into an empty one and fails the load. Required extensions outside an allow-list (geometry compression, Basis textures) are refused: their decoders would be fetched from a CDN.
- Accessibility: WCAG 2.2 AA — 2.1.1 Keyboard and 2.5.7 Dragging Movements (buttons and keys for every pointer gesture), 2.3.3/2.2.2 (no motion by itself), 1.1.1 (the stage is a labelled group; the still preview has alt text), 4.1.2.
- Performance: viewer route and scene are separate chunks; budget in `apps/web/scripts/check-bundle-budget.mjs` runs after every `vite build`; the canvas renders on demand (`frameloop="demand"`), not 60 fps.
- Reliability: a re-signed `download_url` for the same object (polling, focus refetch) does not download the model again; leaving the page aborts the download and disposes geometry, materials, textures and the renderer.

## Out of scope

- Comparing two models in 3D, annotations on the model (KILN-11), animations, wireframe/material inspectors, Draco/meshopt/Basis decoders, AR, full-screen mode, downloads of the original file from the UI.

## Design

- **API**: `VersionOut.download_url: string | null` — `AssetService._version_file` signs the version's `object_key` with the same window-pinned signer, lifetime and `Cache-Control` as previews (ADR 0008; no new decision). Only `ready` versions get one (the worker has checked the file); exposed by `GET /assets/{id}` and `GET /asset-versions/{id}`. OpenAPI and web types regenerated.
- **Data**: none (no migration).
- **Route**: `/assets/$assetId/view` as `assets_.$assetId.view.tsx` (full width, outside the list-detail layout, like compare); search `version` (positive integer, same parser rules as compare). `pickViewable(versions, number)` returns the version to show (named and ready, else the newest ready) and whether the URL must be corrected.
- **Components** (`src/features/viewer`): `ViewerPage` (four states, heading focus, back link) → `ModelViewer` (download, progress, error with preview fallback, toolbar, key handling; the scene comes in through a `scene` prop, defaulting to a `React.lazy` import, so tests inject a fake renderer) → `ModelScene` (the only module importing three/r3f: `Canvas` with `frameloop="demand"`, transparent clear over the surface token, `RoomEnvironment` through `PMREMGenerator`, `OrbitControls` with damping off under reduced motion, framing to the bounding box, a `ViewerController` with `rotate`, `pan`, `zoom`, `reset`). An error boundary turns a WebGL start failure into the `webgl` error.
- **File loading**: `useModelFile(url, sizeBytes)` streams the response (progress from `Content-Length`, else the declared size), aborts past the cap or when unmounted, then `inspectGlb` checks it; it re-downloads only when the object (URL without its signature) or the attempt changes.
- **States**: loading (progress bar + still preview underneath), preparing (indeterminate, while parsing), ready (canvas + controls enabled), error (message, preview, Try again when it can help); page: loading skeleton, not found, load error with retry, nothing to view (empty state).
- **UI (compact / medium / expanded)**: compact and medium: back link, h1, stage (square, full width), toolbar (rotate ◀ ▶ ▲ ▼, zoom + −, pan, Reset view) wrapping in rows, key help, facts. Expanded (≥ 840 px): grid `minmax(0, 1fr) 20rem` — stage left (max block size `70dvh`), side panel right with toolbar, keys and facts. Tokens: surface/surface-raised, outline, focus, space-2…6, radius-lg, target-min/primary. Nearest existing component: `ComparePage`.
