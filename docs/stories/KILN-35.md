# KILN-35: Visual redesign — app shell, dark-first design system, gallery and detail polish

- Release: v0.2 · Status: doing · Owner: Claude (deliver-loop)

## Story

As an **artist or art lead using Kiln every day**, I want the app to look and work like a professional creative-review product — a real app frame, a neutral dark interface that lets the art speak, a gallery with a proper toolbar and edge-to-edge previews, and an inspector for the selected asset — so that I trust it with the studio's work and find, upload and review assets quickly.

INVEST: Independent ☑ (no API change) · Negotiable ☑ · Valuable ☑ (the owner: "looks amateur") · Estimable ☑ · Small ☐ → split into six commits (ui, shell, gallery, detail, compare/viewer, e2e) that each pass the gates · Testable ☑

## Non-functional

- Accessibility (WCAG 2.2 AA): axe serious/critical = 0 on gallery, detail (both tabs), compare and viewer in **both** themes and both projects (desktop, Pixel 7), and on every story in both themes; 1.4.10 reflow (no horizontal scroll at 412 px, checked in e2e); 1.4.13 tooltips hoverable, dismissible with Escape, shown on focus; 2.5.7 a button for every drag; 2.4.11 scroll padding for the sticky bar and the bottom bar; tabs and segmented controls follow WAI-ARIA / native radio keyboard rules; colour never alone (status words, the selected ring plus `aria-current`).
- Performance: first load 124.7 kB gzip (116.2 at KILN-9); the font is a CSS asset with `font-display: swap`; `@kiln/ui` marks only CSS as side effects so unused components are tree-shaken; previews keep fixed intrinsic sizes (no CLS).
- Security: no new data flow; the search field submits nothing; theme choice is the only thing stored (`localStorage`, no personal data); no inline script (CSP).

## Out of scope

Real search (KILN-15), more navigation destinations, list view, a thumbnail-size slider, hover scrub, pause/resume uploads, an account-wide upload history, folder uploads.

## Design

- **Tokens** (`packages/ui/src/tokens/tokens.css`): primitives (zinc 0–950, ember, green, amber, red, blue, sky) → semantic roles (`surface`, `surface-sunken/raised/overlay/hover/pressed/selected`, `on-*`, `primary(-hover)`, `outline(-variant)`, status, `focus`, `tooltip`, `scrim`, `checker-a/b`) for dark (default) and light (`prefers-color-scheme` unless `data-theme`); type scale around a 14 px UI size and 16 px body; radius, elevation, motion, layers and shell sizes. Contrast table: `docs/delivery/KILN-35/contrast.md`.
- **Theme**: `useTheme` (choice → system → dark), `applyStoredTheme()` before the first render in `main.tsx` (no inline script).
- **Shell** (`AppShell`): grid; compact = bar + content + fixed bottom navigation; ≥ 600 rail (80 px), ≥ 1200 sidebar (220 px); sticky bar; `overflow-x: clip`. Actions slot (Upload) and overlays slot (tray, drop overlay) filled by the root route.
- **Gallery**: `/assets` validates `kind`, `sort`, `size`; `visibleAssets()` filters and sorts the loaded pages; `AssetCard` is a link card with a middle-ellipsis name (`splitForMiddleEllipsis`) and a separate View in 3D link (no nested interactive content). Grid columns from the list pane's container width (`--kiln-card-min` 168 px, small 132 px).
- **Uploads**: `UploadButton` (top bar, empty state), `UploadDropOverlay` (reads the open asset from the query cache, never fetches), `UploadTray` (new-asset rows, collapse state derived from the row count), `UploadList` (rows, summary, focus after Remove); `UploadPanel` and `Dropzone` were removed.
- **Inspector** (`AssetDetail`): header, actions (links styled with `buttonClassName`), preview, `Tabs` with `UploadList` + `VersionTimeline` and the Info facts; `NoSelection` fills the empty pane.
- **Layout per size class**: compact — one pane, bottom bar, tray above it; medium — rail, one pane; expanded — rail, grid + 320–400 px sticky inspector; large — sidebar. Nearest existing components matched: `ListDetail`, `ErrorState`.
